# Bola de basquete 3D

Bola de basquete modelada e texturizada no Blender e exibida no navegador com Three.js (WebGL).

**Ver online:** https://danielimpulso.github.io/bola-basquete-3d/

- `index.html`: a página interativa (girar, quicar, zoom)
- `bola_basquete.glb`: o modelo 3D com as texturas de cor, rugosidade e normal
